Grafana Loki Integration

1. Go through the link for quick start - https://grafana.com/docs/loki/latest/get-started/quick-start/quick-start/
2. Create a folder Embarkx-EcomApplication-Microservice/CentralisedLoggingWithGrafanaLoki/evaluate-loki
3. From the doucmentations in point 1, execute the commands and download all 3 files in the path frompoint 2. 
4. Now all the 3 microservice logs are configured on Embarkx-EcomApplication-Microservice/logs.
5. We have to configure this logs to flow to Grafana Loki.
6. Alloy is log collector.

--------- Changes in evaluate-loki to read the logs --------------------
1. Changes to be made in docker-compose.yml
2. In docker-compose alloy - this does the scraping of logs, we need to mount the "logs" folder to some volume in container
	alloy->volumes-> - ../../logs:/logs-parent:ro
3. AFter this make the changes in alloy-local-config.yml, as set in the project structure.
4. Do docker-compose down then docker-compose up -d, this will restart the docker. Restart ll the microservice as well. 
5. Access this http://localhost:3000/?orgId=1&from=now-6h&to=now&timezone=browser -> Menu-> Explore -> Loki.
6. File-name -> /logs-parent/order-microservice.logs
